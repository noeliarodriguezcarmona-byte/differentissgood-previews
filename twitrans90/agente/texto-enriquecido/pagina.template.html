Texto enriquecido de la base de conocimiento

Cada ficha es un tema de la base de conocimiento de Javier, con títulos, negritas y listas. Copia la ficha y pégala tal cual en el editor de texto enriquecido de la plataforma.

  1. Pulsa «Copiar» en una ficha, o «Copiar todo» si tu plataforma acepta un solo texto.
  2. En la base de conocimiento del agente, crea una entrada de texto enriquecido.
  3. Pega con Ctrl+V (o Cmd+V). Se mantienen los títulos y las negritas.

Las notas internas de «pendiente de confirmar con el cliente» no están aquí, para que el agente no las use. Si algo cambia, se actualiza primero la base de conocimiento y luego estas fichas.
